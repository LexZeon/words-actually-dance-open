# Privacy and local data · 隐私与本地数据

[English](#english) · [简体中文](#简体中文)

## English

The public release is a local player by default. It does not register an app account, connect to the original developer's private Site collaboration library, automatically upload music, text, spectra or reading activity, or integrate an app-operated behavioural analytics service. Access to the public website still passes through hosting infrastructure. The hosting layer may process IP addresses, browser information and basic access telemetry. These local-processing statements describe this application's code; they do not mean that the website's host processes no network-access data.

Text, preferences and likes are stored on the current device. The browser uses local storage for the current origin; Windows uses the application's user-data directory. Music playlists and decoded data are mainly kept within the current process and released when it closes. Removing the application files does not necessarily remove user data. Export any text you need before clearing that data.

After you explicitly select system or shared audio, the app analyses the sound only on your device. The browser may require a sharing session that also includes screen access; the product does not display, save or upload the screen image. It does not fall back to the microphone when no sound is available. Stopping sharing or closing the app releases the session.

The source tree retains optional web collaboration modules for technical research. The normal public entry point does not mount them. Before enabling such a service, the deployer must configure authentication, storage, privacy and content rules. The repository contains no account, Site identity or credential that grants access to the original private materials.

Public demonstrations with sound capture only the application's own page under an isolated test configuration, using project-created music and text. They do not record other windows, system audio mixes, user notes or account pages. Song-linked previews/GIFs may show silent recordings of the application's own generated interface; they include neither the third-party song audio nor its source video. The full song demonstrations with sound remain local/private. A silent application preview is separate from distribution of a third-party recording.

## 简体中文

公开发行默认是本地播放器，不注册本应用账号，不连接原开发者私密Site的协作库，不主动上传音乐、文案、频谱或阅读行为，也未接入本应用自建的行为统计服务。公开网页访问仍经过托管基础设施；托管层可能处理IP、浏览器信息和基础访问遥测。上述本地说明针对本应用代码，不等于网站托管方不处理网络访问数据。

文案、偏好和点赞保存在当前设备。浏览器使用当前来源的本地存储；Windows保存在应用用户数据目录。音乐列表和解码数据主要保留在本次进程内，关闭会释放。卸载程序文件不一定移除用户数据；清理前先导出需要的文案。

用户主动选择系统／共享声音后，应用仅在本机分析声音。浏览器可能要求带画面的共享会话；产品不显示、保存或上传屏幕画面。麦克风不是无声时的回退来源。停止共享或关闭程序会释放会话。

源目录中保留可选网页协作模块用于技术研究；普通公开入口不挂载它，启用服务前需要部署者自行配置鉴权、存储、隐私与内容规则。仓库中没有可访问原私有资料的账户、Site身份或凭据。

公开有声演示仅录制隔离测试配置下的软件自身页面，配乐及文字为自产，没有录其他窗口、系统混音、用户笔记或账户页面。关联歌曲的预览／GIF可展示本应用自产界面的无声录像，不含第三方歌曲音频或其源视频，有声歌曲完整版仍只留本地私有。无声应用预览与分发第三方录音是不同内容。
